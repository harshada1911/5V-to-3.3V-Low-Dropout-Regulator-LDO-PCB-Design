# 5V to 3.3V LDO Regulator PCB

A 2-layer PCB design for converting a +5V DC input to a regulated +3.3V output using a Low-Dropout Regulator (LDO).

## Features

- Input: +5V DC
- Output: +3.3V DC
- 2-layer FR-4 PCB
- Input and output decoupling capacitors
- Designed using Altium Designer 26.8.1

## PCB Stackup

- Top Layer – 1 oz Copper
- FR-4 Dielectric
- Bottom Layer – 1 oz Copper

## Applications

Suitable for powering 3.3V microcontrollers, sensors, and other low-voltage electronic circuits.
